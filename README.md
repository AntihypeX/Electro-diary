# Кабинет секретаря Electro-diary

## Установка

1. В Query Tool базы проекта выполните сначала `migrations/01-student-profile.sql`, затем `migrations/02-secretary.sql`. Если первое расширение карточки уже установлено, его повторный запуск допустим.
2. Скопируйте содержимое каталогов `api/` и `frontend/` в одноимённые каталоги проекта. Общие `api/auth.php`, `api/database.php` и `frontend/index.css` берутся из существующего проекта.
3. Войдите через `frontend/index.php` аккаунтом с ролью `secretary`. Откроется `frontend/secretary.php`. Доступ проверяется по роли существующей системы авторизации.

В архив включён обновлённый `frontend/index.php` на основе присланной страницы входа. Если в рабочем файле появились другие правки, перенесите только маршрутизацию:
- В обработчике успешного входа добавьте в `match` строку `'secretary' => 'secretary.php',`.
- При рендере страницы перенаправляйте уже вошедшего секретаря на `secretary.php`, как это сделано для преподавателя.
- Страница входа должна подключать `../api/current-user.php`, чтобы поддерживать версии auth.php без getCurrentUser().

## Корпуса, группы и специальности

В присланной базе у групп отсутствовала привязка к корпусу. Миграция создаёт справочник `campuses` и поле `stud_groups.campus_id`. Пока корпус не назначен, группу можно найти через «Корпус не указан» и выбрать при зачислении.

Названия корпусов и соответствие групп заполняются по реальным данным учебного заведения. Пример для Query Tool, замените названия на свои:

```sql
INSERT INTO public.campuses (name)
VALUES ('Корпус 1')
ON CONFLICT (name) DO NOTHING;

UPDATE public.stud_groups
SET campus_id = (SELECT id FROM public.campuses WHERE name = 'Корпус 1')
WHERE name = 'ИВТ-21';

SELECT g.id, g.name AS group_name, c.name AS campus
FROM public.stud_groups g
LEFT JOIN public.campuses c ON c.id = g.campus_id
ORDER BY g.name;
```

Группы используются из существующей `stud_groups`. Специальности выбираются из `education_specialties`. Пример пополнения справочника:

```sql
INSERT INTO public.education_specialties (code, name)
VALUES ('09.02.07', 'Информационные системы и программирование')
ON CONFLICT (code, name) DO NOTHING;
```

## Работа

**Студенты.** Фильтры по корпусу, группе, студенту и статусу обучения. В списке выводится до 30 студентов на странице. «Карточка» открывает все разделы личных данных. Изменения вступают в силу после кнопки «Сохранить изменения».

**Зачисление.** Отдельная вкладка. Обязательно укажите ФИО, группу и дату зачисления. Другие сведения можно заполнить позже. Семья и предыдущее образование поддерживают несколько записей, прописка и проживание заполняются отдельно. Логин и пароль можно задать вручную или получить автоматически. После успешного зачисления они один раз выводятся на странице для передачи студенту. В базе хранится хеш пароля.

**Отчисление.** В карточке нажмите «Отчислить», укажите дату, номер приказа, причину и подтвердите. Студент появится в фильтре «Отчислен». Его карточка, аккаунт и записи об успеваемости сохраняются. Личные данные можно исправлять и после отчисления. Данные приказа сохраняются при таких исправлениях.

Создание аккаунта и всей карточки выполняется в одной транзакции. Повторная отправка той же формы зачисления обрабатывается без повторного создания студента. Версия карточки защищает от перезаписи параллельных изменений из другого окна. Если версия устарела, откройте карточку заново.
