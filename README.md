# Обновление четырёх кабинетов Electro-diary

## Установка

Сборка объединяет последние подготовленные кабинеты студента, преподавателя, секретаря и заведующего отделением.

1. Примените `migrations/04-cabinets.sql` в Query Tool базы проекта. Она расширяет итоговую аттестацию видом «Зачёт» и добавляет хранение аватарок. Повторное применение допустимо.
2. Затем примените `migrations/05-topics.sql`. Она добавляет вид занятия к справочнику тем.
3. Скопируйте файлы `api/` и `frontend/` в соответствующие каталоги проекта.
4. Обновите страницу браузера с очисткой кеша CSS и JavaScript.

Предполагается, что ранее уже применены миграции преподавателя `teacher-cabinet.sql`, расширение карточки студента `01-student-profile.sql`, миграция секретаря `02-secretary.sql`. Обновление работает с общей PostgreSQL проекта.

Существующие `api/auth.php`, `api/database.php` и настройки подключения используются из вашего проекта. В архиве есть обновлённая общая страница `frontend/index.php` с переходами по ролям. Если в рабочей версии появились собственные изменения после предыдущих архивов, перенесите их перед заменой. Роли остаются student, teacher, secretary, head.

## Студент

- «Моя успеваемость» читает оценки из базы и располагает несколько отметок за день в одну горизонтальную строку.
- «Расписание» показывает один день и пары на этот день. Стрелки переключают дни. Кнопка «Текущая» открывает выбор даты, ссылка «Сегодня» возвращает к сегодняшнему дню.
- «Аттестация за месяцы» показывает месячные отметки по предметам с выбором учебного года и семестра.
- «Итоговые оценки» показывает экзамены, дифзачёты и зачёты.
- «Моя группа» показывает название группы, корпус и полный список одногруппников с датами рождения, телефонами и электронной почтой.

## Преподаватель

- Главная показывает занятия сегодня, пары с незаполненными отметками и студентов с двойками либо пропусками за последние 30 дней. Из рабочих списков можно перейти в журнал.
- Расписание переведено на дневной вид с выбором даты.
- «Аттестация» содержит месячные и семестровые отметки.
- «Итоговые оценки» содержит отдельные колонки экзамена, дифзачёта и зачёта с фильтрами группы, предмета, студента, учебного года и семестра.
- Нажатие на результат открывает выбор и подтверждение сохранения. Зачёт имеет значения «зачтено» и «не зачтено». Экзамен и дифзачёт используют 2, 3, 4, 5, н.
- Доступ к итоговым оценкам определяется занятиями преподавателя в выбранном учебном году. Сохраняются проверки группы студента и защита от перезаписи изменившейся отметки.

## Секретарь

«Группы» показывает корпус, название и численность каждой группы. «Подробнее» открывает её список студентов. Форма создания группы позволяет указать название, корпус и классного руководителя. Руководитель обязателен, поскольку исходная схема требует `stud_groups.class_teacher`.

Названия корпусов и профили руководителей используются из справочников базы. Название группы ограничено 10 символами согласно текущему полю базы. Повторное создание того же названия не добавляет дубликат.

## Заведующий отделением

«Группы» показывает корпус, число студентов, средний балл и пропуски. «Подробнее» выводит студентов выбранной группы с их средними баллами и пропусками. Доступны шесть сортировок для обоих списков:
- А–Я и Я–А;
- средний балл по убыванию и возрастанию;
- пропуски по возрастанию и убыванию.

В этих списках учитываются все сохранённые оценки за занятия студентов текущего состава группы, включая историю до перевода. Средний балл равен сумме оценок 2–5, делённой на их количество. Пропуски считаются по отметкам н/Н. Пустой средний балл выводится прочерком и располагается после числовых значений при сортировке.

## Аватарки и телефоны

Нажмите на квадрат рядом с именем и выберите JPEG, PNG или WebP размером до 2 МБ и до 2048 × 2048 пикселей. Аватарка привязана к авторизованному аккаунту и хранится в базе. Для сохранения не нужна отдельная папка загрузок. PHP должен разрешать загрузки такого размера через upload_max_filesize и post_max_size.

На телефоне обычные таблицы списков превращаются в карточки с подписями полей. Матрицы оценок сохраняют горизонтальную прокрутку, чтобы оставались видны даты, предметы и отметки. Изменение аватарки, создание групп и выбор результатов требуют JavaScript.

## Проверка

Проверены на отдельной PostgreSQL со структурой присланного дампа:
- все четыре роли и страницы кабинетов;
- горизонтальные оценки;
- дневное расписание и выбор даты;
- создание группы и сортировки групп / студентов;
- сохранение зачёта преподавателем и чтение результата студентом;
- отдельные аватарки четырёх аккаунтов и отклонение неподдерживаемого файла;
- ширина страниц при экране 390 пикселей;
- повторное применение миграции.


## Доработка журналов, тем и фильтров

В журнале преподавателя нажатие на плюс открывает компактную панель рядом с ячейкой. Все варианты отметок видны сразу, выбор сохраняет отметку. Для дополнительной оценки снова нажмите плюс в той же ячейке. При изменении существующей отметки сначала подтвердите редактирование в этой панели.

Тема выбирается из `lesson_topics` по связи `subj_id` с предметом. Новые темы при сохранении пары не создаются. Вид занятия хранится в `lesson_topics.lesson_type` и имеет значения «Лекция», «Практическая», «Экзамен». Если вид темы задан, он применяется к выбранной паре и не переопределяется вручную. Для прежних тем с пустым видом остаётся выбор вида конкретной пары.

Проверить справочник можно в Query Tool:

```sql
SELECT t.id, s.name AS subject, t.name AS topic, t.lesson_type
FROM public.lesson_topics t
JOIN public.subjects s ON s.id = t.subj_id
ORDER BY s.name, t.name, t.id;
```

Пример назначения вида существующей теме. Замените 123 на её реальный идентификатор:

```sql
UPDATE public.lesson_topics
SET lesson_type = 'Практическая'
WHERE id = 123;
```

После выбора темы и сохранения пары её практический столбец серый, экзаменационный — чёрный. В экзаменационном столбце отметки показываются чёрным текстом на белом фоне. Изменение справочника тем само по себе не перекрашивает ранее сохранённые пары: вид конкретной пары хранится в `lessons.lesson_type`.

У студента месячные и итоговые результаты используют матрицу в стиле «Моей успеваемости». В обоих разделах есть фильтры предмета, всех учебных лет и всех семестров. В итоговых оценках также можно выбрать вид результата. По умолчанию показывается вся история. Разные преподаватели за один период не перезаписывают отметки друг друга при отображении.

Во всех кабинетах фильтры применяются при изменении выбора. Кнопки «Показать» и «Найти» заменены на «Сбросить фильтры». В журнале студента сброс применяется сразу на странице, в остальных разделах открывает текущую вкладку с исходными фильтрами. «Открыть» в календаре относится к выбору дня расписания.

Проверены все 18 основных вкладок на широком экране и при ширине 390 пикселей. Дополнительно проверены быстрое выставление / добавление / изменение оценок, выбор темы только своего предмета, цвета практического и экзаменационного столбцов, фильтры результатов и контакты одногруппников.

## Исправление панели отметок, зачётов и сброса фильтров

После предыдущих миграций выполните `migrations/06-attestation-na.sql` и скопируйте все файлы `api/` и `frontend/` из этой версии. Миграция заменяет прежние «н» в итоговых аттестациях на «н/а». Отметки посещаемости в evaluations остаются «н». Для зачёта доступны «зачтено», «не зачтено» и «н/а».

Во всех PHP-страницах добавлена версия CSS и JavaScript на основе содержимого файла. Это обеспечивает загрузку новых обработчиков и стилей после обновления сборки.

В журнале плюс открывает варианты оценок рядом с ячейкой. Для нескольких отметок за одно занятие нажмите «Несколько оценок за занятие», выберите нужные оценки и нажмите «Сохранить оценки». Выбранную оценку можно убрать из набора кнопкой с крестиком. Дополнительную оценку также можно поставить повторным нажатием плюса. «н» используется как единственная отметка отсутствия.

Месячная и семестровая аттестация и итоговые оценки используют такую же компактную панель. Существующая отметка меняется после подтверждения. Практический столбец окрашен в #ededeb.

Текстовые результаты отображаются в прямоугольниках по ширине текста. Сброс фильтров встроен в HTML страниц и доступен даже при проблеме с загрузкой JavaScript. Применение выбранных фильтров по-прежнему автоматическое.
