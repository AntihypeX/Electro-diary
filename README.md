# Кабинет заведующего отделением Electro-diary

## Установка

Кабинет рассчитан на общую базу уже установленных кабинетов преподавателя и секретаря.

1. Скопируйте файлы из `api/` и `frontend/` в одноимённые каталоги проекта.
2. В Query Tool базы проекта выполните `migrations/03-head-indexes.sql`. Скрипт добавляет индексы для просмотра оценок. Повторное выполнение допустимо.
3. Войдите через `frontend/index.php` аккаунтом с ролью `head`. Откроется `frontend/head.php`.

Общие `frontend/index.css`, `api/auth.php` и `api/database.php` используются из проекта. Файл `api/secretary-fields.php` содержит общие названия разделов и полей карточки. Он включён в архив для подключения на новой странице.

Если кабинеты преподавателя и секретаря ещё не установлены, сначала примените их миграции:
- `teacher-cabinet.sql` из архива преподавателя;
- `01-student-profile.sql` и `02-secretary.sql` из архива секретаря.

Они создают тип занятия, итоговые аттестации, расширенные разделы карточки и справочник корпусов. Данные студентов, занятий, оценок, групп и корпусов читаются из общей базы проекта.

## Страница входа

Включённый `frontend/index.php` основан на последней присланной странице с маршрутизацией для преподавателя и секретаря. Добавлен переход для роли `head`.

Если рабочий index.php уже содержит другие изменения, перенесите только:
- `'head' => 'head.php',` в обработчик успешного входа;
- перенаправление уже вошедшего пользователя с ролью head на head.php при рендере страницы;
- подключение `../api/current-user.php`, если оно ещё не используется.

В текущей схеме роль head уже предусмотрена. Для проверки аккаунтов:

```sql
SELECT a.id, a.login, r.name AS role
FROM public.auth a
JOIN public.roles r ON r.id = a.role_id
WHERE LOWER(BTRIM(r.name)) IN ('head', 'заведующий отделением', 'заведующий кафедрой');
```

## Разделы кабинета

**Студенты.** Выбор корпуса, группы и студента. В списке видны контакты и статус обучения. Полная карточка показывает личные сведения, документы, обучение, прописку, проживание, семью, предыдущее образование, воинский учёт, судимость, медицинские сведения и трудоустройство. Кнопка «Все оценки» открывает оценки студента за все годы и предметы.

**Оценки.** Строки матрицы — студенты выбранной группы, колонки — занятия с предметом, датой и номером пары. В ячейке видны все отметки за занятие. Выбор студента оставляет одну строку. Ниже отображаются месячные, семестровые и итоговые аттестации. Предусмотрены фильтры по учебному году, семестру и предмету.

**Средние баллы.** Таблица показывает каждую группу, число студентов, количество числовых оценок, пропуски и средний балл. Верхние показатели позволяют сравнить выбранную группу со всеми группами. При выборе корпуса общий показатель ограничивается этим корпусом. Выбор группы выделяет её в таблице, общий показатель продолжает учитывать все группы по остальным фильтрам.

**Экзамены.** Две отдельные таблицы показывают оценки за занятия с типом «Экзамен» и итоговые результаты с kind = exam из аттестации преподавателя. Итоговые дифзачёты доступны в разделе «Оценки».

## Правила расчёта и просмотра

- Средний балл рассчитывается по числовым оценкам за занятия из evaluations. Каждая отметка 2, 3, 4 или 5 учитывается один раз. Пропуски и пустые значения исключаются из расчёта.
- Общий средний балл равен сумме всех этих оценок, делённой на их количество. Округлённые средние групп не усредняются.
- Итоговые аттестации показываются отдельно от оценок за занятия. Они не добавляются повторно к средним баллам.
- Если числовых оценок нет, выводится прочерк.
- Состав группы берётся из текущего students.in_group, включая отчисленных студентов с сохранённой карточкой. История выбранных студентов включает их оценки до перевода в эту группу. Для итоговой аттестации дополнительно указана группа при выставлении.
- По умолчанию выбраны все годы и семестры. Учебный год охватывает сентябрь — август, первый семестр — сентябрь — декабрь, второй — январь — июнь, как в ранее созданной карточке студента.
- Для итоговой аттестации период означает месяц или семестр, к которому относится результат. Он определяется полем period_start, а не датой фактического проведения экзамена.
- Занятия выводятся по 24 колонки на странице. Средние баллы относятся ко всему выбранному периоду и сохраняют значение при переходах между страницами занятий. Итоговые отметки выводятся по 50 записей на странице.
- Доступ к кабинету проверяется по роли head. Запросы просмотра выполняются в транзакции PostgreSQL с режимом READ ONLY.
